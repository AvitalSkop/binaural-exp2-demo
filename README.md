# binaural-exp2-demo

**Live demo: https://avitalskop.github.io/binaural-exp2-demo/** (listen with headphones)

Static research demo for binaural HRTF-conditioned target speaker extraction (Experiment 2): listening examples,
evaluation results and training progression. `site/` is the only deployed directory and everything in it is public.
No build step (HTML, CSS, vanilla JavaScript modules, inline SVG).

Deployment: every push to `main` runs `.github/workflows/deploy-pages.yml`, which validates the site with
`tools/check_site.py` and publishes `site/` to GitHub Pages (`site/index.html` is the root). The site is `noindex`.

- `site/data/*.json` — sanitized metrics, generated by a private export tool that is kept outside this project.
- `site/audio/exNNN/*.wav` — approved stereo WAVs, byte-identical copies (SHA-256 recorded in `site/data/meta.json`).
- `tools/check_site.py` — static validation (leak scan, schema/consistency, audio integrity, required statements).
- `tools/browser_check.py` — headless Firefox check (WebDriver BiDi) with phone/desktop, light/dark screenshots.

Preview locally (fetch and Web Audio need http, not file://):

    python3 -m http.server 8765 --bind 127.0.0.1 --directory site
    # open http://127.0.0.1:8765/

Model colours = the internal Listening Explorer palette (same in light and dark), display order B, C, D, E1, F, each with a
fixed marker shape: B Spatial Features #1baf7a (diamond), C Concat #2a78d6 (circle), D TCSA #eda100 (triangle),
E1 Hadamard #8e44ad (inverted triangle), F FiLM #eb6834 (square). Colour-vision check: adjacent pairs ΔE ≥ 23; weakest
non-adjacent pairs C/E1 (deuteranopia ΔE 6.8) and D/F (normal vision ΔE 13.7), so marker shapes carry identity too.
